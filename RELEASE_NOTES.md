Последняя опубликованная версия: [GitHub Releases](https://github.com/Evgeniyinline/diplom-JS-PW/releases/latest).

## Как добавить новый релиз

1. Создать файл `release-notes/vX.Y.Z.md`.
2. Добавить версию первой строкой в таблицу выше.
3. Создать Git-тег `vX.Y.Z` на релизном коммите.
4. Опубликовать GitHub Release из созданного тега и текста нового файла.
