# v1.1.0 — Allure Notifications 6.0.8

**Дата выпуска:** 29 июля 2026

## Кратко

Telegram-уведомления обновлены до **Allure Notifications 6.0.8**. Добавлен настраиваемый коллаж со статистикой по UI/API-тестам, общей длительности выполнения и повторным попыткам.

Изменения относятся только к тестовой инфраструктуре и не затрагивают продуктовый код приложения.

## Что изменено

- `allure-notifications` обновлён до версии **6.0.8** и подключён как npm-зависимость вместо запуска Java JAR.
- Добавлена круговая диаграмма с процентом успешного прохождения и общим количеством тестов.
- В панели `Suites` тесты разделены на группы `UI` и `API`.
- Добавлена панель `Total duration (sec.)`:
  - суммарная длительность API-тестов;
  - суммарная длительность UI-тестов;
  - общий итог `TOTAL = API + UI`.
- Добавлена панель `Retries by layer`, показывающая количество повторных попыток отдельно для `UI` и `API`.
- Ретраи не увеличивают количество тестов и не учитываются повторно в длительности: используется итоговая попытка каждого теста.
- Для UI/API установлены единые цвета во всех групповых диаграммах.

## Новые диаграммы

| Диаграмма | Назначение |
|---|---|
| Current status | Процент успешности и общее количество тестов |
| Suites | Количество UI- и API-тестов |
| Total duration | Суммарная длительность API, UI и всего запуска в секундах |
| Retries by layer | Количество повторных попыток по UI/API |

## Польза для проекта

- Результат запуска читается непосредственно в Telegram без открытия полного отчёта.
- UI- и API-части прогона легко сравнивать по количеству, длительности и ретраям.
- Статистика не искажается повторными попытками тестов.
- Ссылки на Allure Report, TestOps, GitHub Actions и Release Notes доступны из одного сообщения.
