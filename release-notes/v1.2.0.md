# v1.2.0 — Расширенная аналитика автотестов

**Статус:** черновик

**Дата подготовки:** 30 июля 2026

## Кратко

Telegram-уведомление разделено на краткую сводку и подробную диагностику. Оно дополнено метриками стабильности, производительности и причин падений. Диаграммы с отсутствующими проблемами скрываются автоматически.

## Что добавлено

- В панели `Suites` отображаются количество пройденных тестов, общее количество и pass rate отдельно для `UI` и `API`.
- Размер шрифта в панели `Suites` увеличен для чтения уведомления с телефона.
- Рассчитываются количество и процент flaky-тестов: тест считается нестабильным, если он прошёл только после неуспешной попытки.
- Добавлена панель `Run timing`:
  - фактическое время запуска Playwright;
  - сумма длительностей тестов;
  - изменение суммы длительностей относительно предыдущего запуска.
- Добавлена панель `Slowest tests` с тремя самыми медленными итоговыми попытками.
- Добавлена условная панель `Stability signals` для flaky- и skipped-тестов по слоям.
- Добавлена условная панель `Failure categories` с группировкой ошибок по типам:
  - `Timeout`;
  - `Assertion`;
  - `API / Network`;
  - `Fixture / Setup`;
  - `Product error`;
  - `Test error`.
- Панель `Retries by layer` скрывается, если ретраев не было.
- В Telegram-текст условно добавляются строки `Пропущено` и `Нестабильно`.

## Два изображения в Telegram

- `allure-summary.png` содержит результат прогона, `Suites`, общую длительность и `Run timing`.
- `allure-details.png` содержит ретраи по UI/API, сигналы нестабильности, самые медленные тесты и категории ошибок.
- Обе картинки отправляются одним Telegram-альбомом, а текст и ссылки добавляются только к первой картинке.
- GitHub Actions сохраняет оба PNG в artifact `allure-notification`.

## История запусков

- Для Allure Report 3 подключён `history.jsonl`.
- История переносится из ветки `gh-pages` перед генерацией отчёта и сохраняется в новый отчёт.
- История ограничена последними 20 запусками при построении аналитики уведомления.

## Технические изменения

- Добавлен Playwright-репортёр, сохраняющий фактическую длительность всего запуска.
- Расчёт метрик вынесен в отдельный модуль и покрыт unit-тестами.
- Добавлен детерминированный генератор двух PNG для согласования оформления без запуска тестов и отправки сообщения в Telegram.
- Добавлена отдельная отправка Telegram-альбома через метод `sendMediaGroup`.
